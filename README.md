# TASK MANAGER FULLSTACK

## Bahasa Indonesia

Task Manager adalah aplikasi manajemen tugas fullstack yang dikembangkan menggunakan Flutter sebagai frontend dan Spring Boot sebagai backend. Aplikasi ini membantu pengguna mengelola tugas harian secara digital.

### Fitur

- Login dan registrasi pengguna
- Tambah, edit, hapus, dan cari task
- Filter task berdasarkan status dan kategori

### Teknologi

Flutter, Dart, Provider State Management, Spring Boot

### Cara Menjalankan

Backend: `./mvnw.cmd spring-boot:run`, Frontend: `flutter pub get` lalu `flutter run`

---

## English

Task Manager is a fullstack task management application developed using Flutter as the frontend and Spring Boot as the backend. This application helps users manage daily tasks digitally.

### Features

- User login and registration
- Create, edit, delete, and search tasks
- Filter tasks by status and category

### Technologies

Flutter, Dart, Provider State Management, Spring Boot

### How to Run

Backend: `./mvnw.cmd spring-boot:run`, Frontend: `flutter pub get` then `flutter run`
